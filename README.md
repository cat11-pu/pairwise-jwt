# jwt

一个只依赖 Python 标准库的令牌声明校验内核：三段点分结构的拆分、base64url 解码、
JSON 文档解析、有效期窗口（生效时刻与过期时刻）、受众与签发者匹配、声明类型校验、
时钟偏移容忍，以及按类别区分的错误。全部是内存里的纯计算，不验证签名、不实现任何
加密算法、不读写文件、不联网。

调用方把当前时刻自己传进 `validate`，所以同一个令牌在测试里可以确定性重放，不用碰
系统时钟。

- 令牌形状：`header.claims.signature`，恰好三段，每段非空
- base64url：无填充的 URL 安全字母表 `A-Z a-z 0-9 - _`，段里不得出现 `+`、`/`、`=`
- 头部与载荷各是一段 base64url 承载的 JSON **对象**；签名段原样保留，不做解码
- 窗口：`nbf - leeway <= now < exp + leeway`，到点即过期；`nbf`、`exp`、`iat` 都是整秒
- 受众：`aud` 可以是字符串，也可以是字符串数组，按完整值匹配
- 签发者：`iss` 按完整值精确匹配
- 错误分两族：结构/解码类与声明类，各自还有更细的子类

## 目录

- jwt/core.py：解码、窗口、受众与签发者匹配、声明类型校验
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
